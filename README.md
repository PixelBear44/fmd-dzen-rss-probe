# FMD – Dzen RSS technical probe

This is a public **technical-only** GitHub Pages fixture. It is deliberately empty:
there are no articles, images, authentication credentials, or Dzen API calls.

- `/` checks static HTTPS hosting.
- `/feed.xml` is a valid **empty** RSS 2.0 feed for checking HTTP delivery and XML syntax. **It is not evidence of Dzen RSS eligibility or ingestion.**
- `/status.json` is a static fixture, not measured telemetry.

No publishing pipeline is installed here. No user articles or photos should be
added without a separate media-rights and publication gate.

The operational runbook, checks, and unpublished project state remain in the
private handoff archive outside this public repository.
